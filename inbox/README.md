# inbox

Research projects in flight, one directory each. As many at once as are open.

A project leaves here by `git mv` into `<year>/<slug>/`, where `<year>` is the year of its first commit. It leaves once `FINDINGS.md` holds a recommendation, or once work on it stops and a note names what stopped it.

Starting one: [../AGENTS.md](../AGENTS.md#starting-a-project). The discovery interview comes before the directory exists.

Per-project files, from [../templates](../templates):

| File            | Holds                                                 |
|-----------------|-------------------------------------------------------|
| `README.md`     | scope and expectations, agreed with the user up front |
| `CHATLOG.md`    | the discussion, verbatim, IRC format, append-only     |
| `REFERENCES.md` | every source read, appraised, including the dropped   |
| `FINDINGS.md`   | the shortlist of three and the recommendation         |
| `artifacts/`    | code, data, benchmark output, charts, captures        |
| `notes/`        | per-source extracts                                   |
